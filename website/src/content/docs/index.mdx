Russet is a native implementation of AutoPkg, the tool that Mac administrators
use to download software, package it, and import it into Munki. Russet runs
your existing recipes with the same preference keys and file locations, and
it doesn't need Python. Its `russet` command accepts the same verbs and options
as the `autopkg` command. On macOS, it installs next to Python AutoPkg without
changing it, keeps the previous Russet installation so that you can roll back,
and also runs recipes on Linux and Windows.

:::note[Release status]
Russet doesn't have a published release yet. Its first release is 0.1.0, and
until it's published, you build Russet from source. For details, see
[Install Russet](/get-started/install/).
:::

## What you can do with Russet

<CardGrid>
	<Card title="Run the recipes you have" icon="rocket">
		Russet reads plist and YAML recipes, parent recipes, and overrides, and it
		implements AutoPkg's built-in processors under the same names.
	</Card>
	<Card title="Install next to AutoPkg" icon="random">
		Russet installs in its own folder with its own helper services, so Python
		AutoPkg keeps working. The installer keeps the previous Russet installation
		for rollback.
	</Card>
	<Card title="Skip the Python runtime" icon="seti:rust">
		Russet is a single native executable, plus two helper services on macOS. It
		never runs Python processors or a bundled interpreter.
	</Card>
	<Card title="Verify what you run" icon="approve-check">
		Recipe overrides keep their parent recipe trust information, and Russet
		checks every recipe before it runs any of them.
	</Card>
	<Card title="Import into Munki" icon="document">
		Russet generates Munki pkginfo files natively and rebuilds catalogs for
		file-based Munki repositories.
	</Card>
	<Card title="Run on Linux and Windows" icon="laptop">
		Download, metadata, and Munki catalog recipes run on Linux and Windows, and
		platform-specific steps fail with a clear error.
	</Card>
</CardGrid>

## About the name

Russet takes its name from russet apples, whose rough skin has a rust-brown
color. The name refers to Rust, the programming language that Russet uses.
