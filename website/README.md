# Russet documentation site

This directory contains the Russet documentation site, built with
[Starlight](https://starlight.astro.build/). The site is published at
<https://weswhet.github.io/russet/>.

```sh
cd website
npm install
npm run dev        # open http://localhost:4321
```

The pages live in `src/content/docs/`. They follow the
[Google developer documentation style guide](https://developers.google.com/style);
see [CONTRIBUTING.md](CONTRIBUTING.md) for the conventions and for the build,
preview, and lint commands.
